# Opponent tracks

Scripted placeholder opponents (see `knowledge/mtg-strategy/opponent-archetype-tracks.md` and the
`OpponentTrack` type in `app/src/core/types.ts`). Bracketed names like `[burn spell]` are role
placeholders rendered as generic cards; replace with real, Scryfall-verified names when a track is
"specialized" to a real deck. Validate every file with the zod schema in `app/src/core/opponent/schema.ts` (to be written).
